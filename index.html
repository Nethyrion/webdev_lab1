A Little About Me

Hello everyone and welcome to my first website for this class.

This isn't my first time with coding HTML pages, this is more of a refresher for my own personal enrichment. My first Web Development experience was years ago with an HTML for Dummies book and the Adobe Dreamweaver CS4 software. I taught myself because I liked it and found it fun. Back then there weren't many no-coding programs freely available so you had to do it from scratch if you didn't have access to them.

In recent years I've been using drag and drop page builders to build websites which certainly cuts down on time, but it also feels restricting when it comes to how you want something to be designed on the page in a specific way and the program can't do it out of the box.

I decided to get back into learning this again so I can design things the way I want, and have it look exactly like how I see it in my mind instead of compromising on what the WYSIWYG software can do.
